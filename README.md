**행사로 달라지는 길, 내 차에 맞게 준비하고 음악으로 즐기다.**

> 경로 주변 행사 안내, 도착 배터리 예측, 충전소 경유, 행사장 통과 음악을 제공하는 Pleos 차량 앱

- **공모전**: 2026 현대자동차그룹 차량용 앱 개발 공모전
- **팀**: Miraero
- **플랫폼**: Pleos Connect

## 주요 기능

- **행사·배터리 안내**
  - 경로 주변 행사와 내비게이션 정체 정보 확인
  - 배터리 잔량·남은 거리·에어컨 상태로 도착 잔량 추정
  - 도착 예상 잔량이 10% 미만이면 충전소 경유 제안

- **충전소 경유**
  - 행사장 주변 충전소를 제외하고 충전기 상태·우회 거리 기준으로 선정
  - 운전자가 수락하면 순정 내비게이션 경유지로 추가

- **행사장 통과 음악**
  - 행사장 통과 시점에 맞춰 15초 하이라이트 재생
  - 경기장 시나리오에서는 스코어 한 줄 표시

- **P단 정차 카드**
  - 현재 위치·목적지 반경 2km에서 오늘 열리는 축제 조회
  - 행사 정보·추천곡 미리듣기·행사장 길 안내 제공

## 차량 특화 요소

- **Vehicle SDK**: 배터리·에어컨·기어 상태 조회 및 변화 구독
- **NaviHelper**: 길 안내 감지, 위치·목적지·정체 정보 수신, 경유지 추가
- **운전 상황별 화면**: 주행 중 간단한 안내, P단에서 상세 정보 제공
- **알림 반복 제한**: 같은 알림은 15분 이내 반복하지 않음

## 사용 흐름

1. 순정 내비게이션에서 목적지 설정 및 길 안내 시작
2. 주변 행사 확인 및 도착 배터리 계산
3. 배터리 부족 시 충전소 경유 제안
4. 행사장 통과 시 음악 재생
5. 정차 후 축제 정보·추천곡 확인

## 핵심 로직

- **판단 시작·갱신**
  - 길 안내 시작(`ROUTE_GUIDING`)을 감지하면 행사 매칭과 배터리 계산 시작
  - 위치·배터리·공조 상태가 바뀌면 다시 계산

- **도착 배터리 계산**
  - `도착 예상 잔량 = 현재 잔량 - 주행 소모량 - 정체 중 소모량`
  - 주행 소모량은 남은 거리와 기본 전비로 계산
  - 정체 중 소모량은 정체 시간과 에어컨 ON/OFF별 소모율로 계산
  - 현재 배터리 용량 77.4kWh·전비 5.0km/kWh를 기본값으로 사용
  - 도착 예상 잔량이 10% 미만이면 충전 제안

- **충전소 선정**
  - 현재 위치에서 1~5km 이내, 행사장 반경 1.5km 밖의 충전소를 후보로 선정
  - 빈 충전기가 있는 곳을 우선하고 우회 거리가 짧은 순으로 선택
  - `우회 거리 = 현재 위치→충전소 + 충전소→목적지 - 현재 위치→목적지`
  - 수락 시 `addWaypoint`로 순정 내비 경유지에 추가

- **행사장 통과 음악**
  - 남은 거리·시간으로 평균 속도를 구하고 행사장까지의 도달 시간 추정
  - 도달 시간이 7.5초 이하이면 15초 하이라이트 재생 시작
  - 위치가 갱신될 때마다 통과 시점 재계산

- **알림·데이터 처리**
  - [그냥 가기] 선택 후에는 도착 예상 잔량이 이전보다 5%p 이상 낮아질 때만 재알림
  - 행사와 겹치지 않는 경로에는 행사 관련 알림을 보내지 않음
  - 충전소 데이터는 내비 위치 수신 시 미리 조회하고 10분간 캐시
  - 외부 API 조회 실패 시 시연용 샘플 데이터로 대체

- **iTunes Search API**: 추천곡·미리듣기 조회

## 현재 구현 범위

- **실제 연동**: 차량 상태, 순정 내비, 축제·충전소 조회, 추천곡 미리듣기
- **샘플 시연**: 행사 기반 정체 판단, 행사장 4곳의 통과 음악, 경기 스코어
- **기본값 사용**: 배터리 용량·전비·공조 소모율
- **API 실패 대응**: 샘플 데이터로 대체
- **에뮬레이터 대응**: Virtual Console 차속을 이용한 시연 주행 모드

> 배터리 잔량은 기본값을 사용하는 추정치이며 실제 주행 결과와 다를 수 있습니다. 충전기 상태 역시 조회 시점과 도착 시점에 차이가 있을 수 있습니다.

## 실행 방법

### APK로 실행

1. 상단 링크에서 APK 다운로드
2. Pleos Connect 에뮬레이터 실행
3. ADB로 APK 설치

   ```bash
   adb install -r miraero_roady_release.apk
   ```

4. 에뮬레이터에서 로디 실행
5. 순정 내비게이션에서 길 안내를 시작하고 Virtual Console로 차량 상태 조작

### 소스 코드로 빌드

1. 저장소를 클론하고 Android Studio에서 열기

   ```bash
   git clone https://github.com/miraero-team/Miraero.git
   cd Miraero
   ```

2. Android SDK 37 및 Pleos 개발 환경 준비
3. 프로젝트 루트 `local.properties`에 API 키 설정
   - Android Studio가 생성한 `sdk.dir` 값은 유지

   ```properties
   DATA_GO_KR_KEY=YOUR_CHARGING_API_KEY
   FESTIVAL_API_KEY=YOUR_FESTIVAL_API_KEY
   ```

4. Gradle Sync 완료 후 빌드

   ```bash
   # macOS / Linux
   ./gradlew assembleDebug

   # Windows
   gradlew.bat assembleDebug
   ```

5. Pleos 에뮬레이터에 설치 후 실행

- **직접 빌드한 Debug APK 위치**: `app/build/outputs/apk/debug/app-debug.apk`
- **API 키 관리**: `local.properties`는 커밋하지 않으며, 빌드 시 `BuildConfig`로 주입
